# 流动的校园：由我们构成

首都经济贸易大学数字美育互动装置原型。匿名校园照片以时间河的方式流动，点击照片可进入粒子记忆；最后一张空白拍立得支持上传已有照片或现场拍摄、粒子化处理和 15 字以内留言。

## 本地预览

在项目目录启动静态网页服务，然后访问 `http://127.0.0.1:8780/`。摄像头功能需要在 `localhost` 或 HTTPS 环境中使用。

## 更新网站

双击 `同步到GitHub.bat`，本地改动会提交并推送到 GitHub。GitHub Pages 会在推送后自动更新线上网站。

> 原始摄像头画面不会上传；当前生成的粒子卡片仅保存在本次浏览器会话中，刷新后清空。
